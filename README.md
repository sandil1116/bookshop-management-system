# Bookshop Management System

##  Overview
The Bookshop Management System is a Java-based application developed using NetBeans to manage book inventory, sales, and records efficiently.

---

##  Features
- Add, update, delete books
- Manage book inventory
- User-friendly interface
- Data management system

---

##  Technologies Used
- Java
- NetBeans IDE
- Swing (GUI)
- MySQL (if used)

---

##  How to Run
1. Open NetBeans
2. File → Open Project
3. Select this folder
4. Run project
